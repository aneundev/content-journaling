====================================================
      컨텐츠 저널링 도구   사용 설명서
====================================================

안녕하세요!

이 도구는 유튜브 영상 주소를 넣으면
그 영상의 썸네일 · 제목 · 도입부를
정해진 양식대로 분석해 주는 프로그램이에요.

컴퓨터를 잘 몰라도 괜찮아요.
아래 순서대로 천천히 따라 하시면 됩니다.
처음 한 번만 준비해 두면
다음부터는 더블클릭 한 번으로 쓸 수 있어요.

※ 혹시 지퍼 모양 압축 파일 안에서
   이 글을 보고 계신가요?
   그렇다면 먼저 압축부터 풀어 주세요.
   압축 파일을 마우스 오른쪽 버튼으로 누르고
   "압축 풀기..." 를 누르면 됩니다.
   압축을 풀지 않으면 도구가 실행되지 않아요.


[ 차례 ]

  1. 준비물
  2. 처음 실행하기
  3. Claude API 키 만들어 넣기
  4. 영상 분석하기
  5. 끄기와 다시 켜기
  6. 잘 안 될 때

  8. (선택) 긱어스에 바로 올리기


----------------------------------------------------
 1. 준비물
----------------------------------------------------

  ■ 윈도우 10 또는 윈도우 11 컴퓨터

  ■ 인터넷
     처음 실행할 때 필요한 프로그램(약 140MB)을
     자동으로 받아요.

  ■ Claude API 키
     분석을 해 주는 AI를 쓰기 위한 "열쇠"예요.
     유료이고, 만드는 방법은 3번에서
     하나씩 알려 드릴게요.

따로 설치해야 하는 프로그램은 없어요.


----------------------------------------------------
 2. 처음 실행하기
----------------------------------------------------

① 먼저 "차단 해제" 를 해 주세요. (처음 한 번만)
   윈도우는 인터넷에서 받은 파일에
   "차단" 표시를 붙여 둬요.
   이 표시를 지워야 도구가 실행돼요.

   - 이 폴더에 있는 "START" 파일을
     마우스 오른쪽 버튼으로 누르고
     "속성" 을 누르세요.
     (톱니바퀴가 그려진 아이콘이 START 예요)

   - 열린 창의 맨 아래에 있는
     "차단 해제" 네모 칸을 눌러 체크하세요.

   - "확인" 을 누르세요.

   ※ "차단 해제" 가 보이지 않으면
      이미 해제된 거예요. 그대로 넘어가면 돼요.

② 이제 "START" 파일을 더블클릭하세요.

③ 혹시 경고 창이 떠도 놀라지 마세요!

   - "스마트 앱 컨트롤이 안전하지 않을 수 있는
      파일을 차단했습니다" 라는 창이 뜨면
       → "확인" 을 눌러 창을 닫고
       → ①번의 "차단 해제" 를 한 다음
       → START 를 다시 더블클릭하세요.

   - 파란 창 "Windows의 PC 보호" 가 뜨면
       → 창 안의 "추가 정보" 글자를 누르고
       → 새로 나타난 "실행" 버튼을 누르세요.

   - "보안 경고" 라고 적힌 작은 창이 뜨면
       → "실행" 버튼을 누르세요.

④ 검은 창이 열리고 준비가 시작돼요.
   처음에는 필요한 프로그램을 자동으로 받느라
   1~3분쯤 걸려요.
   창을 닫지 말고 잠시만 기다려 주세요.

⑤ 준비가 끝나면 인터넷 브라우저에
   도구 화면이 저절로 열려요.

※ 꼭 기억해 주세요!
   검은 창은 "도구가 켜져 있다"는 뜻이에요.
   도구를 쓰는 동안에는 닫지 말고 그대로 두세요.
   거슬리면 작게 내려(최소화) 두셔도 돼요.
   검은 창을 닫으면 도구가 꺼져요.

※ 이 폴더는 바탕 화면이나 문서 폴더처럼
   찾기 쉬운 곳에 두면 좋아요.
   옮길 때는 폴더를 통째로 옮겨 주세요.
   그래야 기록이 함께 따라와요.


----------------------------------------------------
 3. Claude API 키 만들어 넣기
----------------------------------------------------

도구 화면을 처음 열면 "설정" 창이 떠 있어요.
여기에 Claude API 키를 넣어야 분석할 수 있어요.

키를 만드는 사이트는 영어로 되어 있지만
당황하지 마세요.
아래에 적힌 버튼만 순서대로 누르면 돼요.

① 가입하기
   인터넷 주소창에 아래 주소를 넣고 들어가서
   가입하거나 로그인하세요.

     https://platform.claude.com

② 크레딧 충전하기
   아래 주소로 들어가서 "Buy credits" 를 누르고
   금액을 정해 결제하세요.
   분석할 때마다 여기서 사용료가 조금씩 빠져요.

     https://platform.claude.com/settings/billing

③ 키 만들기
   아래 주소로 들어가서 "Create key" 를 누르세요.
   이름은 아무거나 적어도 돼요. (예: 저널링)

     https://platform.claude.com/settings/keys

④ 키 복사하기
   "sk-ant-" 로 시작하는 긴 글자가 나와요.
   이것이 바로 키예요. 복사 버튼을 눌러 복사하세요.

   ※ 키는 이때 딱 한 번만 보여 줘요.
      놓쳤어도 괜찮아요. 새로 하나 만들면 됩니다.

⑤ 도구에 붙여 넣기
   도구의 설정 창으로 돌아와서
   "Claude API 키" 칸을 한 번 누르고
   키보드의 Ctrl 과 V 를 함께 눌러 붙여 넣은 뒤
   "저장" 버튼을 누르세요.

이제 준비가 모두 끝났어요. 수고하셨어요!

※ 키는 비밀번호와 같아요.
   다른 사람에게 보여 주거나
   카카오톡 같은 곳에 올리지 마세요.
   키를 아는 사람은 내 크레딧을 쓸 수 있어요.

※ 충전한 크레딧은 산 날부터 1년이 지나면
   사라지고 환불도 되지 않아요.
   처음에는 적은 금액으로 시작해 보세요.


----------------------------------------------------
 4. 영상 분석하기
----------------------------------------------------

① 유튜브에서 분석하고 싶은 영상을 열고
   주소를 복사하세요.
   (영상 아래의 "공유" → "복사" 를 누르면 쉬워요)

② 도구의 "유튜브 링크" 칸에 붙여 넣고
   "분석" 버튼을 누르세요.
   (키보드의 Enter 를 눌러도 돼요)

③ 1~2분쯤 기다려 주세요.
   영상 정보를 받고 나면
   분석 글이 써지는 모습이 화면에 보여요.

④ 다 되면 "노션 복사" 버튼을 누르고
   노션이나 긱어스 글쓰기 화면에서
   Ctrl 과 V 를 함께 눌러 붙여 넣으세요.

[ 그 밖의 버튼 ]

  ■ 수정
     분석 글을 직접 고칠 수 있어요.
     고친 내용은 자동으로 저장돼요.

  ■ 마크다운 복사
     서식 기호(#, - 등)가 들어간 글 그대로 복사해요.

  ■ 중단
     분석하는 도중에 멈추고 싶을 때 눌러요.
     (분석하는 동안 "분석" 버튼이 "중단"으로 바뀌어요)

  ■ 최근 분석
     화면 아래 목록에서 예전에 분석한 영상을 누르면
     다시 볼 수 있어요. 최근 50개까지 보관돼요.
     오른쪽의 × 를 누르면 지워져요.

  ■ 설정 (화면 오른쪽 위)
     API 키를 바꾸거나 모델을 고를 수 있어요.

  ■ 사용법 (화면 오른쪽 위)
     그림이 들어 있는 인터넷 설명서가 열려요.


----------------------------------------------------
 5. 끄기와 다시 켜기
----------------------------------------------------

  ■ 끄기
     검은 창을 닫으세요. (오른쪽 위의 X)
     브라우저 화면도 닫으면 돼요.

  ■ 다시 켜기
     "START" 를 다시 더블클릭하세요.
     두 번째부터는 몇 초면 열려요.

  ■ 바탕 화면에서 바로 켜고 싶다면
     "START" 파일을 마우스 오른쪽 버튼으로 누르고
     "보내기" → "바탕 화면(바로 가기 만들기)" 를
     고르세요.
     (윈도우 11에서는 먼저 "추가 옵션 표시" 를
      눌러야 "보내기" 가 보여요)


----------------------------------------------------
 6. 잘 안 될 때
----------------------------------------------------

Q. "스마트 앱 컨트롤이 안전하지 않을 수 있는
   파일을 차단했습니다" 라는 창이 떠요.
A. "확인" 을 눌러 창을 닫으세요.
   그다음 "START" 파일을
   마우스 오른쪽 버튼으로 눌러 "속성" 을 열고,
   맨 아래 "차단 해제" 에 체크한 뒤
   "확인" 을 누르세요.
   이제 START 를 다시 더블클릭하면 실행돼요.

Q. "Windows의 PC 보호" 창에 "실행" 버튼이 없어요.
A. 창 안의 "추가 정보" 글자를 누르면
   "실행" 버튼이 나타나요.

Q. START 를 눌러도 아무 일도 안 일어나요.
A. 위의 첫 번째 답처럼 START 파일의 "속성" 에서
   "차단 해제" 를 한 뒤 다시 실행해 보세요.

Q. 검은 창이 잠깐 떴다가 바로 사라져요.
A. 압축을 풀지 않고 실행했을 가능성이 커요.
   압축을 먼저 풀고, 풀린 폴더 안의 START 를
   실행해 주세요.

Q. 검은 창에 "받지 못했습니다" 라고 나와요.
A. 인터넷 연결을 확인한 뒤
   검은 창을 닫고 START 를 다시 실행하세요.
   회사나 학교 인터넷은 내려받기가 막혀 있을 수 있어요.
   집 인터넷이나 휴대폰 핫스팟으로 해 보세요.

Q. 백신 프로그램이 yt-dlp.exe 나 ffmpeg.exe 를 막았어요.
A. 유튜브 영상 정보를 받는 데 쓰는 프로그램이에요.
   백신에서 "허용"(예외 등록)한 뒤
   START 를 다시 실행하세요.

Q. 브라우저 화면이 저절로 열리지 않아요.
A. 검은 창에 나와 있는 주소를
   크롬이나 엣지의 주소창에 직접 넣어 보세요.
   보통 아래 주소예요.

     http://localhost:4780

Q. "검은 창(START)이 꺼져 있어 연결할 수 없습니다"
   라고 나와요.
A. START 를 다시 더블클릭한 뒤
   도구 화면에서 키보드의 F5 를 누르세요.

Q. "API 키가 올바르지 않습니다" 라고 나와요.
A. 화면 오른쪽 위 "설정" 에서 키를 지우고
   다시 붙여 넣어 보세요.
   키의 앞뒤가 잘리지 않게
   전체를 복사했는지 확인해 주세요.

Q. "API 오류" 와 함께 credit 이라는 말이 나와요.
A. 크레딧을 다 쓴 거예요.
   아래 주소에서 충전하면 다시 쓸 수 있어요.

     https://platform.claude.com/settings/billing

Q. "요청 한도를 넘었습니다" 라고 나와요.
A. 잠시 기다렸다가 다시 분석해 보세요.

Q. "영상 정보를 가져오지 못했습니다" 라고 나와요.
A. 먼저 링크가 맞는지 확인해 주세요.
   비공개 영상, 지워진 영상,
   로그인해야 볼 수 있는 영상은 분석할 수 없어요.
   다른 영상도 계속 안 되면
   검은 창을 닫고 START 를 다시 실행해 보세요.

Q. 분석 결과에 "자막을 받을 수 없어
   확인하지 못했습니다" 라고 나와요.
A. 자막이 없는 영상이라서 그래요.
   썸네일과 제목 분석은 그대로 쓸 수 있어요.


----------------------------------------------------
 7. 자주 묻는 것
----------------------------------------------------

Q. 돈이 드나요?
A. 도구 자체는 무료예요.
   다만 분석할 때마다 Claude API 사용료가
   내 크레딧에서 빠져요.
   얼마나 썼는지는 아래 주소에서 볼 수 있어요.

     https://platform.claude.com/settings/billing

   "설정" 에서 모델을 Sonnet 이나 Haiku 로 바꾸면
   사용료가 줄어들어요.

Q. 내 기록은 어디에 저장되나요?
A. 이 폴더 안의 "data" 폴더에만 저장돼요.
   분석 기록과 API 키가 들어 있으니
   "data" 폴더는 다른 사람에게 주지 마세요.
   "data" 폴더를 복사해 두면 그게 백업이에요.

Q. 내 정보가 밖으로 나가나요?
A. 분석할 때 그 영상의 정보
   (제목 · 자막 · 썸네일 · 도입부 화면)가
   Claude API 로 전송돼요.
   API 키와 분석 기록은 이 컴퓨터에만 있어요.

Q. 처음 실행할 때 무엇을 받는 건가요?
A. 아래 세 가지 프로그램을
   이 폴더 안의 "bin" 폴더에 받아요.
   컴퓨터의 다른 곳에는 아무것도 설치하지 않아요.

     - Node.js : 도구를 실행해요
     - yt-dlp  : 유튜브 영상의 제목과 자막을 받아요
     - ffmpeg  : 영상 도입부 화면을 캡처해요

Q. 새 버전이 나오면 어떻게 바꾸나요?
A. 아래 주소에서 새로 내려받아 압축을 푼 뒤,
   예전 폴더 안의 "data" 폴더와 "bin" 폴더를
   새 폴더 안으로 옮기면 돼요.
   기록과 설정이 그대로 이어져요.

     https://github.com/aneundev/content-journaling

Q. 지우려면 어떻게 하나요?
A. 이 폴더를 통째로 지우면 끝이에요.


----------------------------------------------------
 8. (선택) 긱어스에 바로 올리기
----------------------------------------------------

Aside 브라우저와 Aside CLI 가 설치된 컴퓨터에서는
분석 결과 위에 "긱어스에 올리기" 버튼이 나타나요.
누르면 AG 마스터마인드의 "컨텐츠저널링" 카테고리에
글이 올라가고, 글 맨 위에 유튜브 영상이 들어가요.

  ■ "설정" 에 기수와 이름을 넣어 주세요.
     글 제목이 아래처럼 만들어져요.

       51기 홍길동 컨텐츠 저널링 - 영상 제목

  ■ Aside 브라우저에서 긱어스에 로그인돼 있어야 해요.
     "설정" 에 긱어스 이메일과 비밀번호를 넣어 두면
     로그인이 풀렸을 때 자동으로 로그인해요.

  ■ Aside CLI 설치하는 곳
     Aside 설정 → Developers → Install

Aside 가 없는 컴퓨터에서는 이 버튼이 보이지 않아요.
그럴 때는 "노션 복사" 로 복사해서
긱어스 글쓰기 화면에 붙여 넣으면 돼요.
